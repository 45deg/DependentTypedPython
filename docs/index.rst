Generated mathematical API
==========================

.. toctree::
   :maxdepth: 2

   math-api

This Sphinx index covers the mathematical API. The repository's ``docs/README.md``
indexes the language specifications, development guide, and roadmap.

The standard mathematical API is written in DepPy's checked Python subset.
Its API reference is extracted statically, so documentation generation never
executes proof source files. Example developments are intentionally excluded.
